# 경로 확인

1. 출발과 도착을 ID로 바꾼다.
   - "234호"처럼 관이 없으면 `data/floors/*.json`의 rooms에서 호수를 찾는다. 여러 관에 있으면 사용자에게 묻는다.
   - 출발이 "입구"면 해당 관의 `entrance` 노드를 쓴다. "내 위치"면 `geo:위도,경도`를 받는다.
2. 실행: `node scripts/route.ts <출발> <도착>`
3. 결과를 경로 카드처럼 정리해 보여 준다: 라벨, 걸음, 시간, 거리, 단계별 안내.
4. 이상한 점(큰 우회, 기본값 계단 칸 수 사용, `unknown` 근처 통과)이 보이면 함께 알리고 **route-auditor** 에이전트 검토를 제안한다.
