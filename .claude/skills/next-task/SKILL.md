# 다음 작업 하나 끝내기

1. docs/TASKS.md를 읽고, 위에서부터 체크하지 않은 첫 항목을 고른다. 인자로 항목을 지정하면 그 항목을 한다.
   - `[-]`는 하지 않기로 한 항목(현장 측정 등)이다. 고르지 않고 건너뛴다.
   - "(사용자)" 표시가 있는 항목은 대신할 수 없다. 사용자에게 무엇이 필요한지 알리고, 사용자가 하지 않아도 되는 다음 항목으로 넘어간다.
2. 관련 문서만 읽는다: 기능은 SPEC, 데이터는 DATA_MODEL, 경로는 ROUTING, 위치는 LOCATION, 화면은 UI_GUIDE.
3. 구현한다. 규칙을 지킨다.
   - 걸음과 시간 계산은 `src/routing`만 쓴다. 계산식을 바꾸면 ROUTING.md도 함께 바꾼다.
   - 데이터가 없는 부분은 지어내지 않는다. 필요하면 멈추고 사용자에게 요청한다.
   - 새 로직에는 `tests/*.test.ts` 테스트를 추가한다.
4. 확인한다: `npm test`, 그리고 데이터를 건드렸으면 `node scripts/validate-graph.mjs`.
   - 화면 작업이면 **ui-reviewer** 에이전트로 검토한다.
   - 데이터나 경로 작업이면 **route-auditor** 에이전트로 검토한다.
5. docs/TASKS.md에 `[x]`로 체크하고 커밋한다(`git add` 할 파일을 구체적으로 지정한다).
6. 보고: 한 일, 테스트 결과, 다음 항목, 사용자가 해야 할 일.
