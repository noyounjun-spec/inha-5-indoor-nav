# 평면도 원본

5호관 층별 평면도를 이 폴더에 넣는다. 한 장에 5북·5서·5남·5동이 모두 들어 있으며, 층마다 한 장이다.

- 파일 이름: `{층}.png` (또는 .jpg, .pdf)
  - `B1.png`, `1F.png`, `2F.png`, `3F.png`, `4F.png`
- 데이터화할 때 한 장을 관별 파일로 나눈다: `2F.png` → `data/floors/5N-2F.json`, `5W-2F.json`, `5S-2F.json`, `5E-2F.json`
- 도면에 관 경계(어디까지가 5북관인지 등)가 표시되어 있지 않으면 아래 표의 비고에 적는다.
- 축척 막대나 치수가 보이는 원본이 좋다. 축척이 없으면 복도 하나의 실제 길이를 재서 여기에 적는다.
