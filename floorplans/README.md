# 평면도 원본

5호관 층별 평면도를 이 폴더에 넣는다.

- 파일 이름: `{관}-{층}.png` (또는 .jpg, .pdf)
  - 관: `5N`(5북), `5W`(5서), `5S`(5남), `5E`(5동)
  - 층: `B1`, `1F`, `2F`, `3F`, `4F`
  - 예: `5S-2F.png`
- 여러 관이 한 장에 들어 있는 도면이면 `5호관-2F.png`처럼 층만 붙여 넣는다. 데이터화할 때 관별로 나눈다.
- 축척 막대나 치수가 보이는 원본이 좋다. 축척이 없으면 복도 하나의 실제 길이를 재서 여기에 적는다.
