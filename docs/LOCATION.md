# 위치 추정

실내에서는 GPS가 부정확하다. 그래서 **실외는 GPS**, **실내는 걸음 수·방향·기압**으로 위치를 추정하고, 추정한 위치를 **경로 위에 맞춘다(스냅)**.
경로 비용이 걸음 단위이므로, 실제로 걸은 걸음 수가 곧 경로 진행도가 된다.

## 사용하는 센서(Expo)

| 용도 | 모듈 | 비고 |
|------|------|------|
| 실외 위치 | `expo-location` `watchPositionAsync` | 정확도(`accuracy`)도 함께 받는다 |
| 방향 | `expo-location` `watchHeadingAsync` | 자기장 간섭이 크면 값을 덜 믿는다 |
| 걸음 | `expo-sensors` `Pedometer` | Android는 ACTIVITY_RECOGNITION 권한, iOS는 동작 권한이 필요하다 |
| 층 변화 | `expo-sensors` `Barometer` | 상대적인 기압 변화만 쓴다 |

모든 센서는 실제 기기에서 동작하는지 확인해야 한다. 기압계가 없는 기기도 있다.

## 상태

1. **실외 모드**: GPS 점을 지도에 표시하고, 실외 구간(`outdoor`)에서 진행도를 계산한다.
2. **입구 도착**: 경로의 입구에서 반경 15m 안에 들어오면 실내 모드로 바꾼다. 사용자가 "건물에 들어왔어요"를 눌러도 바꾼다.
   - 이때 기압 기준값을 저장하고, 입구 층을 현재 층으로 정한다.
3. **실내 모드**:
   - 걸음이 들어올 때마다 현재 단계의 남은 걸음을 줄이고, 경로선 위의 점을 그만큼 앞으로 옮긴다.
   - 방향이 경로와 90° 넘게 계속 어긋나면 "경로를 벗어났나요?"를 띄우고 다시 탐색을 제안한다.
4. **층 전환**:
   - 계단이나 엘리베이터 단계에 들어서면, 기준값과 비교한 기압 변화로 높이 변화를 추정한다(대략 −0.12 hPa/m).
   - 추정한 높이 변화가 목표 층 높이에 이르면 **다음 층 도면으로 자동 전환**하고 다음 단계로 넘어간다.
   - 층 높이(m)는 **현장 확인 필요**. 확인 전에는 3.6 m를 쓰고 이 문서에 기록한다.
   - 기압계가 없거나 값이 불안정하면 "3F에 도착했나요?" 확인 버튼으로 대신한다.
5. **보정 지점**: 계단 입구, 층 전환, 문 앞에서 위치를 해당 노드로 다시 맞춰 오차 누적을 줄인다.

## 나중에 추가할 수 있는 것
- 계단·문 앞의 QR 코드나 NFC 스티커로 정확한 위치 보정
- 보행계와 GPS로 사용자 보폭(`STRIDE_M`) 자동 보정
