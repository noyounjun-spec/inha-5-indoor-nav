# 화면 가이드

네이버 지도 도보 길찾기의 **배치와 흐름**을 참고한다.
**금지**: 네이버 로고, 네이버 아이콘, 네이버 초록색(`#03C75A` 계열), 네이버 폰트나 이미지 파일. 앱 이름·스플래시·아이콘은 직접 만든다.

참고용 스크린샷은 `docs/reference/`에 둔다(배치 참고용으로만 쓰고 이미지를 앱에 넣지 않는다).

## 배치 패턴

- **전체 화면 지도 + 아래 시트**: 지도(또는 평면도)가 화면 전체를 쓰고, 정보는 아래에서 끌어 올리는 시트에 담는다. 시트 높이는 접힘, 중간, 펼침 세 단계다.
- **위쪽 출발/도착 패널**(S3, S4):
  ```
  ┌─────────────────────────────┐
  │ ● 내 위치                ⇅  │
  │ ● 5남관 234호            ✕  │
  └─────────────────────────────┘
  ```
- **경로 카드**(S3): 카드마다 아래 줄을 차례로 쓴다.
  1. `4분` (크고 굵게) · `312걸음` · `220m`
  2. 라벨 칩: `최소 걸음` `최단 시간`
  3. 층 이동 막대: `실외 ─ 1F ─ 계단↑ ─ 3F` (구간 길이는 걸음 비율로)
  4. `5남관 정문으로 들어감`
- **단계별 안내**(S4): 왼쪽에 회전·계단·엘리베이터 아이콘, 가운데에 안내 문장, 오른쪽에 걸음 수를 둔다. 층이 바뀌는 곳에는 구분선과 층 배지를 넣는다.
- **내비**(S5):
  - 위쪽 배너: 큰 회전 아이콘, `12걸음 후 좌회전`
  - 오른쪽 세로 층 선택: `4F 3F 2F 1F B1`. 현재 층은 채운 색으로, 경로가 지나는 층은 점으로 표시한다.
  - 평면도: 경로선, 내 위치 점과 방향 부채꼴, 도착 핀
  - 아래 바: `남은 180걸음 · 2분` / `안내 종료`

## 색(앱 자체 팔레트)

| 토큰 | 값 | 용도 |
|------|----|------|
| `primary` | `#3563E9` | 경로선, 주요 버튼, 선택된 카드 |
| `primaryDim` | `#A9BCF5` | 지나간 경로, 다른 층 경로 |
| `accent` | `#F2994A` | 층 이동(계단·엘리베이터) 표시 |
| `start` | `#2BB673` | 출발 점 |
| `end` | `#E5484D` | 도착 핀 |
| `text` | `#1B1D22` / 다크 `#F2F3F5` | 본문 |
| `subtext` | `#6B7280` | 보조 정보 |
| `surface` | `#FFFFFF` / 다크 `#1E2025` | 시트, 카드 |
| `floorBg` | `#F4F5F7` / 다크 `#15171B` | 평면도 바탕 |
| `wall` | `#C9CDD4` | 평면도 벽선 |

## 글자와 아이콘
- 시스템 기본 폰트를 쓴다. 시간은 22pt 굵게, 본문은 15pt, 보조 정보는 13pt다.
- 아이콘은 `@expo/vector-icons`(MaterialCommunityIcons)의 일반 아이콘만 쓴다.

## 평면도 그리기(react-native-svg)
- 도면 이미지를 바탕에 깔고 경로선을 겹친다. 이미지가 없으면 노드와 edge를 선으로 그린다.
- 두 손가락으로 확대하거나 옮길 수 있다. 안내 중에는 내 위치를 따라가고, 사용자가 화면을 움직이면 "현재 위치로" 버튼을 보여 준다.
- 경로선은 두께 6, 끝을 둥글게 한다. 현재 층 구간은 `primary`, 다른 층 구간은 그리지 않는다.

## 접근성
- 터치 영역은 최소 44×44pt다.
- 색만으로 정보를 전달하지 않는다(층 이동에는 아이콘과 글자를 함께 쓴다).
