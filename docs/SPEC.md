# 기능 명세

5호관 근처(실외)에서 출발해 5호관 안의 원하는 방까지 **최소 걸음 수**로 안내한다.
화면 흐름은 네이버 지도 도보 길찾기와 비슷하게 만들되, 로고·아이콘·브랜드 색은 쓰지 않는다(docs/UI_GUIDE.md).

## 사용자 흐름

1. **홈**: 앱을 열면 실외 지도에 내 위치(GPS)가 보이고, 위쪽에 검색창이 있다.
2. **검색**: 도착지를 입력한다.
   - 호수(`234`), 관+호수(`5남 234`, `5S-234`), 방 이름(예: 학과사무실), 별칭으로 찾을 수 있다.
   - 호수는 관마다 따로 매기므로, 여러 관에 같은 호수가 있으면 관을 골라 달라고 한다.
3. **출발지**: 기본값은 "내 위치"(GPS 자동 입력)다. 단, 입구 위경도(`geo`)가 데이터에 없으면 GPS 출발을 쓸 수 없으므로 기본값은 "5호관 입구"이고 "내 위치" 선택지는 보이지 않는다(지금 데이터는 위경도를 넣지 않기로 했다).
   - **근처 호실로 지금 위치 입력**: 실내에서는 GPS가 부정확하므로, 사용자가 근처에 보이는 호실 번호를 입력하면 그 방 문 앞을 출발 위치로 쓴다. 화면에는 "5북관 123호 근처"처럼 보인다. 홈의 "지금 어디에 있나요?" 버튼, 경로 목록의 출발 칸, 내비 중 배너의 위치 버튼(길을 잃었을 때 그 자리에서 다시 찾기)에서 입력한다. 도착하면 도착한 방이 다음 출발 위치가 된다. 다른 방이나 입구로 바꿀 수 있고, 출발지와 도착지를 서로 바꾸는 버튼이 있다.
4. **경로 목록**: 경로 옵션 카드를 여러 장 보여 준다(docs/ROUTING.md의 프로필).
   - 카드마다: 예상 시간(가장 크게), 걸음 수, 거리, 층 이동 요약(예: `계단 1F→3F`), 들어가는 입구
   - 결과가 같은 프로필끼리는 카드 하나로 합치고 라벨만 여러 개 붙인다(예: "최소 걸음 · 최단 시간").
5. **경로 상세**: 카드를 고르면 지도에 경로선이 그려지고, 아래 시트에 단계별 안내가 나온다.
   - 예: `직진 24걸음` → `좌회전 후 12걸음` → `계단으로 1F→3F (48계단)` → `234호 도착`
6. **안내(2D 내비)**: "안내 시작"을 누르면 실행된다.
   - 실외: 지도에 내 위치와 경로가 보인다.
   - 건물에 들어가면 **현재 층 평면도(2D)**로 바뀐다.
   - 계단이나 엘리베이터로 층을 옮기면 **층 도면이 자동으로 바뀐다**(docs/LOCATION.md).
   - 위쪽 배너에 다음 안내가, 아래에 남은 걸음과 남은 시간이 나온다.
   - 층 선택 버튼으로 다른 층을 직접 볼 수도 있다.
7. **도착**: 도착 화면을 보여 주고 안내를 끝낸다.

## 화면 목록

| ID | 화면 | 주요 요소 |
|----|------|-----------|
| S1 | 홈 | 실외 지도, 내 위치 버튼, 검색창 |
| S2 | 검색 | 입력창, 최근 검색, 결과 목록(관·층 표시) |
| S3 | 경로 목록 | 출발/도착 입력 패널, 경로 카드 목록 |
| S4 | 경로 상세 | 지도/평면도 + 경로선, 단계별 안내 시트, 안내 시작 버튼 |
| S5 | 내비 | 다음 안내 배너, 층 도면, 내 위치 점, 층 선택, 남은 걸음·시간 |
| S6 | 도착 | 도착 메시지, 총 걸음·시간 |

## 이번 범위에서 하지 않는 것
- 5호관 외 다른 건물, 로그인, 서버
- Wi‑Fi나 비콘 기반 실내 측위(나중에 LOCATION.md에 추가할 수 있다)

## 정해야 할 것
- 실외 지도: Leaflet + OpenStreetMap 타일(기본값, API 키 필요 없음) 또는 네이버 지도 웹 API(API 키 필요). 바꾸려면 사용자에게 먼저 확인한다.
