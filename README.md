# 5호관 실내 길찾기

인하대 5호관(5북·5서·5남·5동, B1~4F) 안에서 **최소 걸음 수**로 길을 안내하는 웹 앱입니다.
화면 흐름은 지도 앱의 도보 길찾기를 참고했습니다.

## 할 수 있는 것
- 방 검색: 호수(`234`), 관+호수(`5남 234`, `5S-234`), 방 이름·별칭(`화장실`)
- 지금 위치: 근처에 보이는 호실을 입력하면 그 방 앞에서 출발
- 경로 목록: 최소 걸음·최단 시간·계단 이용·계단 없이. 카드마다 시간·걸음·거리, **엘리베이터 이용 / 계단만 이용** 표시
- 경로 상세: 실제 층 도면 위에 경로선, 단계별 안내(직진 24걸음 → 좌회전 → 계단 1F→3F …)
- 안내: 다음 안내 배너, 층이 바뀌면 도면 자동 전환, 남은 걸음·시간

## 실행
Node.js 22.18 이상이 필요합니다.

| 방법 | 명령 |
|------|------|
| Windows에서 바로 | `실행.bat` 더블클릭 |
| 개발 서버 | `npm install` 후 `npm run dev` |
| 배포용 빌드 | `npm run build` → `dist/index.html` 한 파일 (더블클릭으로도 열림) |
| 테스트 | `npm test` · 데이터 검사 `npm run validate` |
| 경로 확인 | `node scripts/route.ts 5N-1F-123 5S-3F-332` |
| 웹에 배포 | `npm run deploy` → 빌드 후 `gh-pages` 브랜치에 올림 (GitHub Pages: https://noyounjun-spec.github.io/inha-5-indoor-nav/) |

## 구성
- `floorplans/` 층 평면도 원본 · `data/floors/` 관·층별 길찾기 그래프(json)
- `src/routing/` 경로 엔진 · `src/screens/` 화면 · `src/ui/` 부품 · `src/lib/` 검색·요약
- `docs/` 기능·데이터·경로·화면 문서, 진행 상황은 `docs/TASKS.md`

## 한계
- 도면에 축척이 없어 복도 폭을 2.7m로 가정했습니다. 걸음 수는 대략값입니다.
- 도면으로 알 수 없는 방·복도·연결은 데이터에서 뺐고, 각 json의 `unknown` 목록에 적었습니다.
- 실내 위치는 GPS 대신 근처 호실 입력으로 정합니다.
